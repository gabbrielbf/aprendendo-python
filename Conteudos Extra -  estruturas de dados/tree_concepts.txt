O que são nós? Ligação de informações não lineares através de uma raiz específica, um exemplo seriam as listas encadeadas.
O que são folhas? Nós isolados no fim das árvores sem ligações abaixo deles.
 Ex.
        A <- Raiz, pai de B, C mas não de D. Porém o A seria o "ancestral" de D
       / \  
      B   C <- Estrutura da árvore
           \
            D <-  Folha

Floresta: São vários conjuntos de 2 ou mais nós isolados não ligados um ao outro

- Árvore binária, o que é? É um modelo de árvore que obriga o dev a fornecer exatamente 2 filhos a cada nó.
 Ex.
        A <- Raiz
       / \
      B   C <- B, C e F são nós interiores, nós que não são nem folhas e nem a raiz
     / \   \
    D   E   F
           / \
          G   NONE <- Quando possuimos algum dos lados de um nó vazio presente nos filhos dos nós antecessores
                       denominamos ele como NONE para preencher determinado espaço "obsoleto". Tal como o C e o F.

    Podemos perceber que cada sub-árvore do exemplo de árvore citado acima é também uma árvore binária, B tem dois filhos D e E e seguindo
    o conceito inicial de árvore binária, D e E também seriam obrigados a implementear dois filhos cada.

- Altura, profundidade e caminhos em ÁRVORES:

 Modelo ex.
                A <- Raiz
              /   \___
             B        E
            / \      /
  folha -> C   D    F
              / \    \
    folha -> G   H    J <- folha
                  \   
          folha -> I 

- Caminho é a sequência de nós que estão interligados entre si onde conseguimos avançar entre eles por meio de arestas conectadas na árvore
 Ex.
    O caminho para chegar a variavel G é determinado por B, D e por último G
O que é o comprimento de um determinado caminho? Seria o número total de nós que estão dentro do caminho, que no caso do exemplo acima seria 3. B, D e G

- Altura é comprimento do caminho entre a raiz e a folha de maior profundidade
O que seria a profundidade? É a distância do caminho de determando nó até a raiz da árvore
 Ex.
    A raiz tem profundidade 1, pois o caminho dela até ela mesma é apenas A
    Os nós B e E tem profundidade 2
    Os nós C, D e F tem profundidade 3
    Os nós G, H e J tem profundidade 4
    O nó I tem profundidade 5, a altura dessa árvore seria o caminho traçado desse nó até a raiz

Altura máxima e altura mínima: Construção de árvore com (n) números de dados, 
qual a altura máxima e mínima que conseguimos construir com esses mesmos 5 dados?
 Ex.
       Máxima (ou zigue-zague):
                A <- Raiz
              /   \___
             B        E
            / \      /   -> Seria o caminho traçado pelos nós até a folha mais profunda de forma encadeada, sem sub-dividir filhos a esqueda ou direita.
  folha -> C   D    F       No exemplo dessa árvore a esquerda, a altura máxima seria o caminho traçado entre A, B, D, H e I.
              / \    \    
    folha -> G   H    J <- folha
                  \   
          folha -> I    # Esse modelo de árvore se torna degenarado, obsoleto, pois trata-se quase literalmente de uma lista encadeada

       fórmula: h(n)max = n # A altura maáxima nesse caso seria 5, pois temos 5 nós que ligam A e I
  ------------------------------------------------------------------------------------------------------------------------------------------------------
       Mínima:
                A <- Raiz
              /   \___
             B        E
            / \      /   -> Seria a preservação da árvore em 3 níveis dos nós, por exemplo: começando pelo pela raiz A, puxando um filho para cada lado
  folha -> C   D    F       do nó B e E e logo após isso defininmos entre: C e D ou C e F, isso não altera o fator 3 níveis de nós.
              / \    \    
    folha -> G   H    J <- folha
                  \   
          folha -> I

       fórmula; h(n)min = 1 + (o PISO de log de n na base 2 (a não ser que o problema computacional diga o contrário, a base desse log sempre vai ser 2!))

       nota -> O que queremos dizer com (1 + PISO de log de n na base 2)?
        Ex.
            Vamos usar x (um número qualquer) por exemplo para melhor compreensão.

              Quando dizemos que o PISO de x é igual a k estamos dizendo primeiro que k é um número inteiro, então o mesmo pertence ao conjunto
              dos números inteiros {-3, -2, -1, 0, 1, 2, 3}

              de forma que k é menor (<) ou igual (=) a x, ou seja: k é o menor número inteiro quese aproxima de x e x é menor que (k + 1)

       Qual o resultado dessa fórmula usando o próprio 5 como excemplo?
           Res.
              1 + PISO de log 5 na base 2
              log na base 2 de 4 = 2 (pois 2² = 4)
              próximo número fechadinho que teríamos é 8
              logo o log de 8 na base 2 = 3

              portanto sabemos que 5 por ser maior do que 4 e menor do que 8
              o logarítmo precisa estar entre 2 e 3 (mais precisamente = 2,32~2)

              o piso disso acima é o menor número que aproxima, no caso 2
              portanto: 1 + 2 = 3

              e de fato, se formos seguir a notação presente na árvore exemplar mínima, vamos que tem exatamente 3 níveis de profundidade.
       
       Notação autoexplicativa:
           
           No primeiro nível temos a raiz, um único elemento - 1
           No segundo nível temos 2 elementos, logo dobramos o valor - 2
           No terceiro nível usamos a mesma ideologia de antes e dobramos novamente caso tivessemos na árvore exemplar um parceiro
           a direita do nó F - 4

           O mesmo valeria para os filhos sub-sequuentes: 8, 16, 32 e por aí vai... Seguindo a metodologia das potências de 2

- Percursos em árvores

  O que é percurso em uma árvore? É uma forma sistemática de passar por todos os nós presentes em uma árvore, quer dizer que não é uma forma qualquer
  no qual não podemos olhar para a raiz, em seguida para uma folha qualquer, não! Essa nomeclatura se dá justamente por existir um padrão, uma ordem pré-definida
  criada para fazermos uma VISITA SISTEMÁTICA aos nós da árvore.
